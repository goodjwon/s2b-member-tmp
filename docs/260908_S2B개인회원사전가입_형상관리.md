## 2. 운영 소스 반영 경로 (안)

s2b.kr 현행 구조 `/S2BNCustomer/S2B/scrweb/{css,js,images}/...` 를 기준으로 기능 단위 하위 폴더 `member/preJoin` 을 신설한다. 기존 `main2020` 과 같은 층위에 두어 사전가입 기능 종료 후 폴더 단위 제거가 가능하도록 한다.

## 3. 반영 시 변경 사항

| 대상 | 변경 |
|---|---|
| CSS·JS·이미지 참조 | `../assets/...` 상대경로 → 2.1 절대경로 |
| `S2B_API` 3개 함수 | 스텁 → `$.ajax` (jQuery 1.12.4, 운영 로드 중) |
| `closePopup()` `goMain()` | `index.html` 이동 → `window.close()` / 메인 이동 |
| `<form data-demo>` | 속성 제거 → `form.submit()` POST |
| `class="dev-note"`, 개발용 링크 주석 | 제거 |
| `<!-- [JSP] -->` 주석 | EL/JSTL 바인딩으로 치환 후 주석 제거 |
| 문자 인코딩 | 운영 JSP가 EUC-KR 이면 저장 인코딩 변환. CSS·JS 내 한글 문자열(알럿 메시지) 포함 |

인코딩은 운영 소스 확인이 필요하다. 현행 메인 페이지는 `charset=EUC-KR` 로 응답한다.
